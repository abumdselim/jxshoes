# P0 — মাস্টার কনটেক্সট

> উৎস: [shopkeeper-professionalization-prompts.md](./shopkeeper-professionalization-prompts.md) (P0 সেকশন, অক্ষত কপি)।
> প্রম্পট সিরিজের পরামর্শ অনুযায়ী এটা `AGENTS.md`-এ বসানো হবে — আপাতত আরেকটা চলমান কাজের সাথে ফাইল-সংঘর্ষ এড়াতে আলাদা সেভ করা হলো; ওই কাজ কমিট হলে `AGENTS.md` তৈরি করে এটা বসাতে হবে।
> নোট: P0-তে "অফলাইন ওয়ার্ক আলাদা ব্রাঞ্চে চলছে" লেখা — বাস্তবে অফলাইন সিঙ্ক কাজ এখন main-এর ওয়ার্কিং ট্রি-তে (আনকমিটেড) আছে (src/lib/offline, src/app/api/sync, docs/OFFLINE_SYNC.md)।

```
তুমি "Shopkeeper" প্রজেক্টে কাজ করছ — বাংলাদেশের ছোট-মাঝারি দোকানের জন্য AI-চালিত শপ ম্যানেজমেন্ট (স্টোরফ্রন্ট + অ্যাডমিন/POS)।

স্ট্যাক: Next.js 14 App Router, TypeScript, Tailwind, Cloudflare Pages (edge runtime, @cloudflare/next-on-pages), KV, R2, Workers AI, Gemini (শুধু ভয়েস)। UI বাংলা-ফার্স্ট।
লক্ষ্য: নিরাপদ, অফলাইন-সক্ষম, মাল্টি-টেনান্ট, প্রফেশনাল মানের সফটওয়্যার।

নিয়ম:
1. edge runtime-এ Node-only API (fs, Node crypto, bcrypt) নয়; Web Crypto ব্যবহার করো।
2. টাকার হিসাব সবসময় integer (পয়সায়), ফ্লোট নয়। UI-তে টাকা দেখাও।
3. নতুন UI টেক্সট বাংলায়। কোড ও কমেন্টের ভাষা ইংরেজি বা বাংলা, তবে ফাইলে ধারাবাহিক রাখো।
4. অফলাইন ওয়ার্ক আলাদা ব্রাঞ্চে চলছে। ক্লায়েন্ট-সাইড ডেটা শেপ (IndexedDB/সার্ভিস ওয়ার্কার) ভাঙার আগে আমাকে জানাও।
5. প্রতিটা কাজে: আগে বর্তমান কোড পড়ো, ফাইল-ভিত্তিক প্ল্যান দাও, আমি OK দিলে কোড লেখো।
6. শেষে tsc --noEmit, next lint, টেস্ট চালাও। যা যাচাই করোনি সেটা স্পষ্ট করে "যাচাই হয়নি" বলো; আন্দাজকে তথ্য বানিও না।
7. স্কোপের বাইরের ফাইল বদলাবে না। কোনো সিক্রেট কমিট করবে না।
8. docs/ROADMAP.md ও সংশ্লিষ্ট docs আপডেট করো।
```
