# ট্র্যাক C — P2 বাকি: E2E চালানো + আসল-ব্রাউজার স্মোক

- **জায়গা:** মূল ট্রি (`D:\1. Data Center\JxShoes`) বা নতুন worktree `test/e2e-hardening` ব্রাঞ্চে
- **লক্ষ্য:** Playwright স্কেফোল্ড (P2-তে বানানো) প্রথমবার সত্যিতে চালানো।

## কাজ
1. `npx playwright install chromium` (ব্রাউজার ডাউনলোড — একবারই)।
2. `playwright.config.ts` + `e2e/smoke.spec.ts` পড়ো — dev-server পোর্ট/env ঠিক আছে কি না।
3. `npm run e2e` চালাও (কনফিগে webServer থাকলে স্বয়ংক্রিয়; না থাকলে `npm run dev`
   আলাদা পোর্টে চালিয়ে base-URL দাও)।
4. ব্যর্থ হলে: স্পেক/কনফিগ ঠিক করে (শুধু টেস্ট-ফাইল — অ্যাপ-কোড ছোঁবে না) আবার চালাও।
5. ফল রেকর্ড করো — কোন স্পেক পাস/ফেল, কারণ। ফিক্স লাগলে কমিট **শুধু টেস্ট-ফাইলে**।

## সমান্তরাল-নিয়ম
- dev-server-এর জন্য `PORT=3100` — অন্য ট্র্যাকের সাথে পোর্ট-কনফ্লিক্ট নয়।
- অ্যাপ-কোড পরিবর্তন দরকার হলে সেটা **স্মোক-টেস্ট ফাইন্ডিং** হিসেবে রিপোর্ট করো, নিজে ঠিক করবে না।
