## মালিকের সিদ্ধান্ত নেওয়ার তালিকা (সিরিজের সেকশন ৪ থেকে)

1. শেয়ার্ড টেনান্ট বনাম ক্লায়েন্ট-ভিত্তিক ডিপ্লয় (সুপারিশ: শেয়ার্ড)।
2. হোস্টিং অ্যাডাপ্টার — P3-র ADR দেখে।
3. SMS প্রোভাইডার ও খরচ-নীতি।
4. প্রাইসিং ও প্ল্যান-সীমা (AI কোটা, SMS, আউটলেট)।
5. নেগেটিভ স্টক নীতি (সুপারিশ: রেকর্ড + অ্যালার্ট, রিজেক্ট নয়)।
6. **জরুরি:** লাইভ সাইটে সত্যিকারের কাস্টমার ডেটা থাকলে P1-এর কোড ফেজ সবার আগে — অডিট রিপোর্ট প্রস্তুত, OK দিলেই worktree-তে কাজ শুরু করা যায়।
